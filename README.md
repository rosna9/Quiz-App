# Quiz App

This is a simple interactive web application where users answer fill-in-the-blank questions. Each question provides word options, and users have 30 seconds to choose the correct answer. At the end of the quiz, feedback is provided based on the user's performance.if user wants to quit middle of quiz ,then he or she can quit 

## Features

- Timed questions (30 seconds per question)
- Multiple word options for each blank
- Auto navigation to the next question after timer ends
- Final score and feedback display
- Responsive and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
